Мы ведем технический проект по реверс-инжинирингу закрытого бинарного формата оффлайн-карт для смарт-часов DT G1.

Мы уже проделали некоторую работу, частично расшифровали архитектуру файлов карт и написали набор утилит на Python для работы с этими картами.

Я прикрепил к сообщению 5 файлов — это наше текущее ядро проекта:

1. dtg1_map_specification.md — наша спецификация формата (реверс-инжиниринг). Изучи её в первую очередь.

2. dtg1_roads_mlp_compiler.py — компилятор геометрии из формата OSM (создает .mlp и кэш метаданных).

3. dtg1_roads_idx_compiler.py — наш компилятор индексов и баз данных (создает .idx и .db и map.name).

4. dtg1_idx_dumper.py — инструмент для создания CSV-дампов из бинарных индексов.

5. dtg1_exporter.py — утилита для обратного декодирования бинарников часов в GeoJSON.



Наша текущая задача:

Слой дорог структура файлов .db и .mlp нам окончательно ясна.

Со структурой файлов .idx есть проблемы: мы можем создать файлы карты с одной дорогой и часы её успешно отображают, если создать файлы с несколькими дорогами, то часы дороги не показывают.

Неясно, или мы сделали ошибку в спецификации, или dtg1_roads_idx_compiler.py неверен.
